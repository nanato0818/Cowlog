# Codexへの依頼：Cowlog ホーム画面用の牛の3Dモデル

## 目的
Cowlog（放牧牛の見守りアプリ、Flutter製）のホーム画面上半分に、選択中の1頭を大きく表示する3Dモデルを作る。利用者は横スワイプで個体を切り替える。

## 作風
- **リアルすぎず、デフォルメしすぎない**。実在の牛の体型比率は保ちつつ、表面は滑らかで細部を省いた、落ち着いた「プロダクトイラスト」寄りの質感。
  - 避けたい例：毛並み・しわ・血管まで描いた写実表現／頭が体の半分ほどあるキャラクター風／目が大きいマスコット調
  - 目安：頭身は実物に近く、目は小さめの黒、輪郭はやや丸める程度
- マットな質感（光沢を抑える）。輪郭線やトゥーン塗りは使わない。
- アプリ全体は白・淡いグレーの地にコンセプト色 `#D9473D`（赤）。牛自体にこの色は使わない。首輪のみ使用可。

## 必要なもの
1. **ホルスタイン**（白地に黒の斑）
2. **茶色の牛**（ジャージー種のような明るい茶色、顔周りやや淡色）
3. **未設定用**（全体を淡いグレー `#C8D1CC` 系の単色にしたもの）

3体は同じメッシュを共有し、マテリアル（またはテクスチャ）だけ差し替えられる構成が望ましい。

### 付属物
- 首にGPS首輪：ベルト（濃いグレー）＋小さな箱型の端末。端末の前面に小さなランプ（マテリアル名 `collar_led`、アプリ側で色を変える）。
- 耳標（黄色）は任意。

## 姿勢・構図
- 立ち姿、四脚接地。斜め前（右前方 約30°）から見て見栄えがよいこと。
- 原点は四脚の中心の接地面。+Y が上、モデルの正面は +Z。
- 全長がおよそ 2 ユニットに収まるスケール。
- 台座・地面は含めない（アプリ側で影を描く）。

## アニメーション（任意・あれば）
- `idle`：呼吸程度のごく小さな上下と、しっぽの揺れ。ループ、3〜4秒。
- `nod`：頭を一度軽く下げて戻す。約0.8秒。

## 出力形式
- **glTF バイナリ（.glb）**、1体につき1ファイル：`cow_holstein.glb`、`cow_brown.glb`、`cow_unknown.glb`
- ポリゴン数：1体あたり **2万三角形以下**（スマートフォンで常時表示するため）
- テクスチャ：使う場合は 1024px 以下、PBR（metallic-roughness）。KTX2 などの圧縮は不要。
- 置き場所：`/Users/murakami/Desktop/Cowlog-Flutter/apps/mobile/cowlog_flutter/assets/models/`
- 確認用に、各モデルを斜め前から撮った PNG（1024×1024、背景透過）も同じ場所に出力する。

## アプリ側の受け入れ（参考）
- 表示枠は `lib/widgets/cow_model_view.dart` の `CowModelView`。現在はホルスタインの画像による仮表示で、モデルが届いたらこのウィジェットの中身だけを差し替える。
- 指で横にドラッグするとページ（個体）が切り替わるため、モデル自体をドラッグで回す操作は付けない予定。ゆっくりした自動回転のみ検討。

## やらないこと
- アプリのコード（`lib/` 配下）は変更しない。
- 既存ファイルの削除・Gitのコミットはしない。
