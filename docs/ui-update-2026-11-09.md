# Cowlog UI変更（2026-11-09）

- 起動後は地図を表示。航空写真を画面の上下左右いっぱいに表示し、ナビゲーションと操作ボタンを上に重ねる。
- 左上に小さなCowlog。説明文・長い判定理由・地図の注意書きは通常画面から削除。デモ識別、通信状態、入力エラー、地図の出典などは短いラベルで残す。
- 白・淡い背景に青緑 `#16796B` を主アクセント、黄土色 `#C69650` を副アクセントとして統一。未測定等には中立のグレーを使用。航空写真そのものの色は変更しない。
- 地図の区画線は既存の5区画の座標を維持。区画名はボタンで表示切替。重なる牛番号ラベルは抑え、番号一覧から詳細を開ける。
- 詳細の「1日の内訳」は外側から活動・非活動・未測定の3本の同心円リング。食事・反芻・睡眠を識別する機能ではない。
- 各リングは、その日すでに経過した時間に対する該当時間の割合。当日の未来の時間を未測定に数えない。
- 中央の活動率と日別棒グラフは、活動秒数 ÷ 測定できた秒数。各区間の百分率の単純平均ではない。
- 7本の棒は各日平均の活動率。選択日は青緑、他日は淡い青緑。欠測は「—」、測定済みの活動0%とは分ける。測定率70%未満の棒の下には黄土色の点を表示し、長押しで測定率を確認可能。
- 日別集計は日本時間の0時から24時。首輪の集計区間は測定時刻が区間の終点という前提。日境界にかかる区間は時間に比例して配分し、同一時刻の重複・重なる区間は二重に数えない。欠測を非活動に置き換えない。
- 日付変更でリング・棒・経路を更新する。経路は全画面へ拡大可能。現在の状態判定・データ取得・番号設定のAPIは変更していない。
- AWSとの実接続、実機での行動分類は追加していない。デモの値は架空のサンプル。

検証：Flutter静的解析とテスト22件成功。iOSシミュレーターで全画面地図のサイズ、リング・日別棒グラフ、経路の全画面化を確認。


## 牛アイコン・地図上部ボタン（同日追記）

- 「牛のようす」の各行に、コード描画の牛アイコンを追加。白黒（ホルスタインの見た目）・茶色・未設定の灰色の3種類。
- デモでは0204と0212を茶色、他を白黒で表示。これはデモの見た目であり、実際の品種を確認した情報ではない。
- 「首輪・番号」の編集から表示アイコンを選択できる。番号と一緒に保存し、実データではサーバーDBの `cow_style` に保持。値は `unknown` / `holstein` / `brown`。未指定・不明値は灰色で、番号から品種を推測しない。
- デモの変更はメモリ内のみで再起動すると戻る。既存DBには既定値unknownの列を追加し、番号変更でも選択済みの見た目を維持する。
- 地図の右上3ボタン（地図切替・全体表示・区画名）を削除。メイン地図は航空写真に固定し、左上ロゴと下部ナビゲーションを維持。ピンチとドラッグで地図操作できる。
- 未登録首輪を手入力で新規追加する画面・APIは未実装。受信済み／登録済みの首輪を一覧に出して番号を割り当てる方式。
- AWSへの配置・接続は行っていない。API契約をAWS側にも反映する必要がある。


## 活動・非活動の2リングへ変更（2026-11-09）

外側を活動、内側を非活動の2本に変更。未測定のリングと凡例は削除しました。各割合は測定できた時間を分母にします。活動率の中央表示と分母を統一し、欠測を非活動に混ぜません。測定ゼロなら割合は未取得（—）で空の軌道だけを表示します。欠測時間は内部の測定率計算には保持します。
