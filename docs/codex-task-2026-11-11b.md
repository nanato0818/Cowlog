## 直す点

### 1. 首輪の端末が「黒い四角」に見える
現状、首の横に浮いた黒い板のように見え、特に丸アイコンでは不具合に見える。
- 首輪は、首を一周する**ベルト**（濃いグレー、幅は首の太さの1/6程度、首の形に沿って密着）として見えるようにする
- 端末は**首の下側（喉の下）**にぶら下がる小さな箱にする。角を丸め、色は濃いグレー（真っ黒にしない）。横から見て体の輪郭から大きく飛び出さない
- 小さな丸アイコンで見たとき、首輪と分かるか、目立たないかのどちらか。黒い四角に見えないこと

### 2. 白黒の斑の縁がギザギザ
- 斑の境目を滑らかにする（ノイズ状のギザギザをなくす）。縁はくっきり、形は有機的な大きめの斑
- 頂点カラーで塗っている場合は、境目付近を細かく分割するか、テクスチャ（1024px以下）に切り替える
- 顔の斑（目の周り・鼻筋）も自然な配置に

### 3. 丸アイコンの切り抜きが偏っている
現状、牛が右に寄って体が途中で切れ、茶色は頭だけが大写しになっている。
- 丸アイコン用の画像（`*_avatar.png`）は、**頭から肩までの斜め前の胸像**に統一する。3種類とも同じ構図・同じ大きさ・同じ位置
- 頭が円の中央、やや上に来る。耳と角が円からはみ出さない。円で切り抜いたとき不自然な切れ方をしない
- 背景は透過

### 4. 全体の作風の微調整
- 目標は「リアル調に、ほんの少しデフォルメ」。現状は目が側面に点で付いていて、おもちゃっぽく見える
- 目は少し大きく、まぶたの膨らみを付けて顔の前寄り・やや上に。鼻先（鼻鏡）はピンク〜灰色がかった肌色で、鼻の穴を自然に
- 耳は頭の横から水平に、角は短く根元が太い
- 脚は今より少し太く、蹄は体と同系の暗色で大きすぎない
- 光沢は抑えたマットな質感のまま。ホームの大きな画像（`cow_*.png`）も同じ品質で作り直す
