# Cowlog Flutter版（2026-10-28）

牛の位置と活動量を首輪の番号で確認する試作アプリ。利用者の指定は **首輪 → AWS → アプリ**。個体台帳・品種・生年月日などの表示と検索は廃止し、番号のみで管理する。

## 起動

```sh
flutter pub get
flutter run
```

指定なしはデモ。画面の値は架空。デモの番号変更はメモリ内のみで、再起動すると戻る。

## 画面

優先一覧／地図／首輪・番号の3タブ。番号検索、状態・位置の絞り込み、日別経路・概算移動距離・活動量比較。白黒テーマ、醍醐牧場の国土地理院航空写真（初期表示）、OpenStreetMapへの切り替え。添付放牧地図の黄線から①〜⑤の5区画を個別に復元し黄色で表示（画像復元境界で、測量値ではない）。⑥は未収録。デモの架空経路も牧場内に配置。首輪・番号画面から受信済み・登録済みの首輪に番号を設定できる。半角数字1〜12桁、先頭ゼロを保持、同じ番号の重複を拒否。番号変更で履歴を消さない。

## サーバー接続

接続フォームは設けない。非公開JSONをビルド時に指定する。

```json
{"COWLOG_DEMO":false,"COWLOG_API_URL":"https://your-api.example/prod/","COWLOG_READ_TOKEN":"replace-read-token","COWLOG_MANAGE_TOKEN":"replace-separate-manage-token"}
```

```sh
flutter run --dart-define-from-file=/absolute/path/to/private-config.json
```

- アプリ起動中、30秒ごとに一覧を再取得。OSが停止するバックグラウンド更新・プッシュ通知は実装していない。
- `GET /v1/dashboard`、`GET /v1/cows/{id}/history?date=YYYY-MM-DD`、`GET /v1/collars` は閲覧権限。
- `PUT /v1/collars/{device_id}/number` は番号管理専用権限。管理トークン未指定なら閲覧のみ。
- サーバー保存成功を確認してから完了を表示。首輪本体へ設定を送る機能はない。
- 固定トークンは試作用。アプリに埋めたトークンを秘密として保護できるとは扱わない。送信用トークンをアプリに含めない。
- 通信エラー時の番号保存・首輪一覧にはキャッシュを使わない。位置・履歴は通信例外時に保存済みの情報を表示し、通信不良を表示する。
- 地図タイルにはインターネット接続が必要。

AWSの接続先やDBサービスは未設定。ローカルAPIの実装とAWSへの配置完了は別。詳細は [現行仕様](../../../docs/current-spec.md) を参照。
