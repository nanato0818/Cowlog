# Codexへの作業依頼（2026-11-11）

あなたは Flutter アプリ Cowlog（放牧牛の見守りアプリ）の改修を担当します。まず次の2つを読んで、現在の状態を把握してください。

- `docs/current-state-2026-11-11.md`（現在の画面仕様・配色・ファイル構成。これが最新）
- `docs/codex-3d-cow-request.md`（3Dモデルの作風・形式の依頼）

アプリは `apps/mobile/cowlog_flutter`。iOSシミュレーター（iPhone 18 Pro、起動済み）で動作確認しています。

## 守ること
- Gitのコミット、stash、checkout、reset、ブランチ操作はしない。作業フォルダに未コミットの変更が多数あるので、消さないこと
- 画面にロゴ・説明文・注意書きを追加しない。見やすさ最優先
- 状態判定・API・番号ルール・データ処理（`lib/state/`、`lib/services/`、`lib/models.dart`、`lib/activity_summary.dart`）は変えない
- コンセプト色 `#D9473D`（`AppColors.accent`）は維持
- 既存テストの意図を壊さない。最後に `flutter analyze` と `flutter test` を通す

## 依頼1：牛を3Dモデルに差し替える（最優先）
- アプリ内で牛を表示している箇所を、すべて3Dモデル（または3Dモデルからの描画）に差し替える
  - ホーム上半分 `lib/widgets/cow_model_view.dart` の `CowModelView`（現在はイラストと2Dアイコンの仮表示）
  - 一覧・首輪番号・編集シートの丸いアイコン `lib/widgets/cow_avatar.dart` の `CowAvatar`（現在はコードで描いた2Dの顔）。小さいので、3Dモデルを斜め前から撮った静止画（透過PNG）を使ってよい
- 作風：**リアル調を基本に、ほんの少しだけデフォルメ**。実物の体型比率と質感を保ち、輪郭と細部をわずかに丸めて整理した程度。キャラクター調・トゥーン調にはしない
- 種類：白黒（ホルスタイン）、茶色、未設定（淡いグレー単色）。首にGPS首輪（濃いグレーのベルト＋小さな端末）
- 形式・置き場所：`docs/codex-3d-cow-request.md` のとおり（`.glb`、1体2万三角形以下、`apps/mobile/cowlog_flutter/assets/models/`、確認用PNGも出力）。この環境には Blender が無い。Python で glTF を直接書き出す等、手元でできる方法で作ってよい（必要なら pip でライブラリを入れてよい）
- ホームでの表示：ゆっくりした自動回転、または静止でよい。**横スワイプは個体の切り替えに使っているので、モデルをドラッグで回す操作は付けない**。スワイプ中の奥行きの動き（`home_screen.dart` の Transform）は残す
- `.glb` を表示するためのパッケージを追加してよい（例：`model_viewer_plus`、`flutter_3d_controller` など。iOSで動くこと、背景透過できることを確認して選ぶ）。表示に失敗した場合は確認用PNGを代わりに出す
- `pubspec.yaml` の assets に追加したファイルを登録すること

## 依頼2：リキッドグラスを修正する
対象：`lib/app_theme.dart` の `Glass`、`lib/screens/root_screen.dart` の下部ナビとレンズ `_Lens`。

- もっと**透き通った**ガラスにする。現在は白が乗りすぎて曇って見える。背景（地図の航空写真・画面の地）がはっきり透けて見えること
- ガラスらしさ：縁の細いハイライト（上辺が明るく下辺がわずかに暗い）、内側のごく弱い反射、背景のわずかな屈折感（拡大やずれの表現は軽く）
- レンズ：移動中と指が触れている間に**少し大きくなる**動きは維持し、タップできたことがはっきり分かるようにする（今より分かりやすく。押した瞬間の反応を早く）
- 白い背景の画面（ホーム・一覧）でもナビの輪郭が見えること。地図の上でも文字とアイコンが読めること
- `Glass` を使っている他の部品（地図の番号帯・右上ボタン、ホームのページ表示、経路全画面の部品）も同じ見た目に揃う

## 依頼3：ゲージの色
- **電池のゲージは緑**。30%以下のときは注意の色（コンセプト色 `#D9473D` で可）
- ホームタブの他のゲージ（活動率・移動距離）の色も、緑の電池と並んで統一感が出るように調整する。原色の信号機配色は避け、彩度を揃えた落ち着いた色に
- 7日グラフ・活動リングはコンセプト色の同系色のまま（`AppColors.ringActive` 等）でよいが、ゲージとの並びで違和感があれば微調整してよい
- 色は `AppColors` に名前付きで追加し、画面側で直接16進数を書かない
